# Proposal Workspace

This directory is a non-authoritative mockup-preparation workspace attached to the draft Dewy restored-hardcover EPP.

It exists so WNPH can develop realistic presentation assets without promoting speculative manufacturing facts into the package.

## Rule

> A proposal is not publication truth, and mockup preparation does not redesign approved cover art.

The recovered Dewy cover image is the graphic source of truth. Historical physical evidence governs the restoration direction. Unknown spine, stock, page-block, and jacket details stay unresolved until they are established.

## Repeatable workflow

1. Start from the owning Manifestation and current publication Expression.
2. Resolve the highest-resolution approved/recovered cover artwork through the governed publication/media seam.
3. Record historically grounded physical facts and approved WNPH restoration choices; leave unknowns unresolved.
4. Use the versioned cloth-hardcover template family.
5. Generate only outputs supported by the available physical/artwork facts.
6. Review front, shelf, three-quarter, and selected/detail views at their intended web sizes.
7. Promote only approved physical values and validated generated assets into `manifest.json`.
8. Add the historically evidenced dust jacket only after approved jacket artwork/specification exists.
9. Validate and seal the EPP separately from any website deployment.
